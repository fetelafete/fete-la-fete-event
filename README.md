# Fête la Fête Event — site vitrine

Site statique gratuit, sans base de données, prêt à être publié sur GitHub Pages, Netlify ou Cloudflare Pages.

## Avant publication
1. Remplacez `https://www.votre-domaine.fr/` par votre vrai domaine dans `index.html`, `robots.txt` et `sitemap.xml`.
2. Remplacez `[Votre téléphone]`, `[Votre e-mail]` et `[Ville / département]`.
3. Dans le lien `tel:`, remplacez `+33000000000` par le vrai numéro.
4. Ajoutez vos vraies photos, avis clients et coordonnées.
5. Créez/optimisez votre fiche Google Business Profile avec exactement le même nom, téléphone et zone de service.

## SEO
Le site comprend un titre SEO, une meta description, une balise canonical, Open Graph, données structurées Schema.org, robots.txt et sitemap.xml.
